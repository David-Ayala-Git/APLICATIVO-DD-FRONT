Como conectar n8n al gateway

URL base de la API http://api-gateway:8080
Autenticacion Authorization: Bearer <jwt>
Obtener el token POST /api/auth/login
Tenant Lo fija el gateway desde el token; no lo mandes a mano

Dentro de la red de Docker usa el nombre del servicio (api-gateway); desde tu maquina, http://localhost:8080. Crea un usuario dedicado para los flujos para poder auditar sus acciones por separado.
